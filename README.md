# Zero to MVP 🚀

مرحباً بك في مستودع **Zero to MVP**! 
هذا المستودع يضم جميع المواد، المشاريع، المبادئ المعمارية، والأدوات الخاصة بالمعسكر التدريبي (Bootcamp) الذي يهدف إلى نقل المتدربين من الصفر إلى بناء منتج أولي قابل للتطبيق (Minimum Viable Product).

## 📁 محتويات المستودع

يحتوي هذا المستودع على عدة مجلدات ومشاريع فرعية أساسية:

### 1. نظام إدارة المعسكر (Camp OS)
- **`camp-os/`**: النظام الأساسي لإدارة المعسكر، مبني باستخدام تقنيات حديثة (Next.js/React)، ويحتوي على لوحات تحكم للمنظمين (Organizers)، الموجهين (Mentors)، الحكام (Judges)، والمتدربين (Participants).

### 2. الحزم التأسيسية (Starter Kits)
مشاريع جاهزة كنقطة بداية للمتدربين لمساعدتهم في فهم المفاهيم بسرعة:
- **`01-vercel-deploy-starter/`**: مشروع لتطبيق أساسيات النشر على منصة Vercel.
- **`02-responsive-ui-starter/`**: مشروع لتطبيق مفاهيم واجهة المستخدم المتجاوبة (Responsive UI).
- **`fresh-cert-project/`** & **`fresh-test-app-3/`**: تطبيقات ومشاريع اختبارية إضافية.

### 3. المواد التعليمية (Bootcamp Materials)
- **`bootcamp_materials/`**: يحتوي على الجداول الزمنية، أدلة المدربين والمتدربين، معايير التقييم، ونصوص الصفحات التعريفية.

### 4. هيكلية البرنامج والتوثيق (Architecture & Docs)
مجموعة من الملفات المعمارية التي توثق تصميم النظام والمشاريع:
- **`architecture/`**: مخططات وقرارات التصميم الخاصة بـ Camp OS.
- **`09_PROGRAM_ARCHITECTURE_V2_LOCKED.md`**: المخطط الهيكلي المعتمد للبرنامج.
- **`11_STARTER_KIT_ARCHITECTURE.md`** والنسخ المحدثة منها.
- **`12_STARTER_KIT_IMPLEMENTATION_PLAN.md`**: خطة تنفيذ الحزم التأسيسية.

## 🚀 البدء السريع (Getting Started)

إذا كنت ترغب في تشغيل **Camp OS** محلياً:

1. انتقل إلى مجلد المشروع:
   ```bash
   cd camp-os
   ```
2. قم بتثبيت الحزم المعتمدة:
   ```bash
   npm install
   ```
3. قم بتشغيل خادم التطوير:
   ```bash
   npm run dev
   ```
4. افتح المتصفح على الرابط [http://localhost:3000](http://localhost:3000).
