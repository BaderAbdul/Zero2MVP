# Levels and Badges

There is exactly one unified progression system in From Zero to MVP. Teams progress through five official levels. Progress is tracked on your physical or digital **Builder Passport** and the central **Leaderboard**.

## Level 1: 🎯 Problem Hunter
- **Mission:** DISCOVER
- **Goal:** Find a real problem worth solving.
- **Deliverables:** Specific target user, clearly defined problem, current solution, why the problem matters, MVP Canvas, Formed team.
- **Definition of Done:** The team can clearly explain: "Who has the problem, what is the problem, and why does it matter?"
- **Evidence:** Completed MVP Canvas.
- **Checkpoint:** Mentor verification of Canvas.
- **Badge Unlocked:** 🎯 Problem Hunter
- **Internal Technical State:** IDEA / VALIDATED PROBLEM

## Level 2: 📐 Product Architect
- **Mission:** DESIGN / FIRST SHIP
- **Goal:** Turn the validated problem into a buildable product scope and deploy the first shell.
- **Deliverables:** Core user flow, MVP scope, one primary user journey, technical feasibility check, initial working project (Public Vercel URL).
- **Definition of Done:** The team has a working project deployed publicly, even if it is only a basic shell (FIRST SHIP).
- **Evidence:** Live Vercel URL.
- **Checkpoint:** Mentor clicks the Vercel URL.
- **Badge Unlocked:** 📐 Product Architect
- **Internal Technical State:** DEPLOYED SHELL

## Level 3: ⚙️ AI Builder
- **Mission:** BUILD
- **Goal:** Build the core product experience.
- **Deliverables:** Functional UI, core interactions, realistic mock data where necessary, one complete core user flow, AI-assisted implementation.
- **Definition of Done:** A user can complete the main product flow from beginning to end, even if data persistence is not yet connected.
- **Evidence:** Live demonstration of the flow in the browser.
- **Checkpoint:** Mentor completes the flow.
- **Badge Unlocked:** ⚙️ AI Builder
- **Internal Technical State:** FUNCTIONAL PROTOTYPE

## Level 4: 🌐 MVP Creator
- **Mission:** CONNECT
- **Goal:** Turn the prototype into a connected product with data persistence.
- **Deliverables:** Firebase connected, Authentication where required, Firestore persistence where required, at least one working data flow.
- **Definition of Done:** The core product data persists successfully. The minimum successful data loop should be: User → Auth → Create → Firestore → Read.
- **Evidence:** Data verified in the Firebase Console.
- **Checkpoint:** Mentor observes data creation and retrieval from Firestore.
- **Badge Unlocked:** 🌐 MVP Creator
- **Internal Technical State:** CONNECTED MVP

## Level 5: 🏆 Founder
- **Mission:** SHIP + PITCH
- **Goal:** Turn the MVP into something the team can confidently demonstrate.
- **Deliverables:** Live Vercel application, mobile verification, basic production/security check, final working core flow, 3-minute pitch, Demo-ready product story.
- **Definition of Done:** The team has a live product URL and can demonstrate the core user journey successfully without security leaks.
- **Evidence:** Completed Gamma deck and flawless Demo run-through.
- **Checkpoint:** Instructor verifies pitch readiness and security.
- **Badge Unlocked:** 🏆 Founder
- **Internal Technical State:** LIVE PRODUCT

## Progression Rules
- **Team Progression:** Teams level up together.
- **Badge Unlock Rules:** Mentors must verify the exact "Evidence" before stamping the Builder Passport.
- **Graduation Criteria:** A team must reach Level 5 (Founder) to present on Demo Day and graduate.
