# From Zero to MVP: 3-Day Builder Schedule

## Day 0 — PRE-CAMP (GET READY)
**Mission:** Arrive ready to build.
- **Technical Preflight:** GitHub, Vercel, Firebase, Antigravity access checked.
- **Initial Idea Submission:** Digital submission of problems to solve.
- **Idea Marketplace:** Pre-camp review of ideas to seed Day 1.
*Output:* Builder Passport issued. *Level Checkpoint:* Pre-requisite.

---

## Day 1 — DISCOVER & DESIGN
**Mission:** DISCOVER → DESIGN → FIRST SHIP
**Progression:** Problem Hunter → Product Architect

- **00:00–00:30 | Mission Brief & Idea Marketplace:** Pitch ideas, form teams (3-4 people).
  *Activity:* Team formation and idea selection.
  *Output:* Formed team, selected problem.
- **00:30–01:15 | Problem Validation (DISCOVER):** MVP Canvas.
  *Activity:* Define Target User, Problem, and Core Value.
  *Output:* Validated Problem (MVP Canvas).
  *Level Checkpoint:* **🎯 Problem Hunter** badge unlocked.
- **01:15–02:00 | Product Architecture & Scope (DESIGN):** 
  *Activity:* Define the one primary user journey and core flow. Introduce Agent-First Building.
  *Output:* Core user flow defined.
- **02:00–03:00 | Ghost Deploy & First Build Sprint (FIRST SHIP):**
  *Activity:* Build a basic shell using Antigravity and deploy it publicly on Vercel immediately.
  *Output:* Deployed Shell (Public Vercel URL).
  *Level Checkpoint:* **📐 Product Architect** badge unlocked.

---

## Day 2 — BUILD & CONNECT
**Mission:** BUILD → CONNECT
**Progression:** AI Builder → MVP Creator

- **00:00–00:15 | Architecture Check:** Review Day 1 shell and plan the day's sprint.
- **00:15–01:30 | Core Interaction Sprint (BUILD):**
  *Activity:* Develop UI, core interactions, and realistic mock data using Agent-First method.
  *Output:* Functional Prototype (One complete core user flow).
  *Level Checkpoint:* **⚙️ AI Builder** badge unlocked.
- **01:30–01:45 | Break & Setup:** Prepare for data integration.
- **01:45–03:00 | Firebase Build Sprint (CONNECT):**
  *Activity:* 75 minutes dedicated to minimum successful data loop: Auth → Create → Firestore → Read.
  *Output:* Connected MVP (Data persists successfully).
  *Level Checkpoint:* **🌐 MVP Creator** badge unlocked.
- **03:00–03:45 | Open Build Lab / Rescue Lane:**
  *Activity:* 45 minutes of flexible time. Mentors deploy Starter Kits (Accelerators) for stuck teams or help advanced teams polish.

---

## Day 3 — SHIP & PITCH
**Mission:** SHIP → PITCH
**Progression:** MVP Creator → Founder

- **00:00–00:30 | Pitch Clinic & Gamma Setup:**
  *Activity:* Learn the 3-minute pitch structure and start deck creation.
- **00:30–01:00 | Final Verification (SHIP):**
  *Activity:* Final push to Vercel (NOT the first deployment). Mobile check.
  *Output:* Live Product URL.
- **01:00–01:15 | Security Checkpoint:**
  *Activity:* Verify no API keys or secrets are exposed in the frontend.
- **01:15–02:00 | Demo Prep & Rehearsal:**
  *Activity:* Finalize pitch deck and practice the live demo. 
  *Output:* Demo-ready product story.
  *Level Checkpoint:* **🏆 Founder** badge unlocked.
- **02:00–03:30 | DEMO DAY:**
  *Activity:* 3-minute pitch + 1-minute Q&A per team.
  *Output:* Pitched Product.
- **03:30–04:00 | Judging & Awards:** Winners announced.
